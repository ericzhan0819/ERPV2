- Admin／manager／sales 主要路由可用，manager／sales 的管理員或敏感路由仍被阻擋。
- 390px Sidebar focus、body scroll lock、無水平 overflow、Theme 與 Account 基本操作通過。

```text

```

針對 browser smoke 的 SQLite fidelity 落差，另於本機 MariaDB 10.11 的明確可拋棄
`erpv2_v15_test` schema 執行 v1.5 username 專用 gated integration：

```text
APP_ENV=testing
DB_CONNECTION=mysql
DB_DATABASE=erpv2_v15_test
MYSQL_CONCURRENCY_TEST_CONNECTION=mysql
MYSQL_CONCURRENCY_TEST_DATABASE=erpv2_v15_test
RUN_MYSQL_CONCURRENCY_TESTS=1
./vendor/bin/phpunit tests/Feature/UserAccountMysqlIntegrationTest.php

PASS：2 tests／36 assertions
```

這兩項直接驗證 MariaDB case-insensitive username unique／migration rollback order，以及兩個
真實連線搶同一 username 時 loser 轉為 validation error。測後已刪除
`erpv2_v15_test`；既有 `erpv2` 的 users／cash_accounts／vehicles 筆數仍為 `3／3／9`。
其餘 15 個 environment-gated tests 屬薪資、時區與車輛並發，非第 15 部分帳號 browser
workflow 的資料庫語意，本輪未重跑。

Build 保留既有大於 500 kB chunk warning，本部分沒有新增 dependency 或 runtime 程式。

## 6. 資料與環境安全

- Firefox 與 Chrome 各使用獨立 `/tmp` SQLite，沒有讀寫既有 MySQL／MariaDB 或開發資料。
- Browser smoke 的 SQLite 不涵蓋 MySQL／MariaDB collation、unique constraint 與真實跨連線
  競態語意；該面向由 `UserAccountMysqlIntegrationTest` 的 gated tests 負責，執行結果另列於
  本報告自動回歸段落。
- 所有暫存 SQLite、driver processes、browser profiles 與下載的 Chrome binary 均已刪除；
  可重跑 driver source 保留於 `docs/smoke/`。
- 獨立 Laravel／Vite／driver processes 均已停止。
- 產品 runtime 沒有因 smoke 而修改；repository 只新增 PLAN 註記、報告與可重跑 driver。
