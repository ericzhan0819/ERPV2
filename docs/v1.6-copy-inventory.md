# ERPV2 v1.6 UI Copy 盤點

日期：2026-07-29
起始基準：`539599d`（`v1.5-smoke-passed`）

本文件記錄 v1.6 使用者可見輔助文案的 A／B／C／D／E 分類與處理方向。表格是實作前基準；各章實作時若實際程式狀態與初判不同，必須先更新本表並說明理由，再修改 UI。

## 分類

| 類別 | 處理 |
|---|---|
| A | 與頁名、label、按鈕或狀態重複，直接刪除 |
| B | 規則仍需常駐，但縮短為單一主要訊息 |
| C | 只在適用狀態顯示 |
| D | 金額口徑、風險、後果、錯誤或空狀態，必須保留 |
| E | 視覺可移除，但保留為 assistive technology 可取得的描述 |

## 共用元件與契約

| 元件／契約 | 決策 |
|---|---|
| `DashboardTrendChart` | description 可縮短或改 E 類，但 `aria-labelledby` 指向的 title／description 必須存在，單位與期間可取得 |
| `MobileFilterDrawer` | 保留可見標題、關閉 accessible name、focus trap、Escape 與 focus return；不以 copy cleanup 改互動 |
| `DebouncedSearchInput` | 保留 visible label；placeholder 只作範例 |
| `CustomerSelect` | 保留姓名與電話 visible labels；loading／無結果不合併；read-only 電話原因不得只靠 placeholder |
| `ThemeToggle` | 現有 `aria-label` 與 `title` 同義；`title` 不是唯一 accessible name，不需建立 tooltip |
| Badge 元件 | 正式狀態文字不得刪除或只靠顏色 |
| `pages/salary/shared.tsx`／`SalaryStatusBadge` | 視為薪資共用呈現元件而非頁面；草稿、已確認、已發薪屬 D 類正式狀態文字，不得刪除或只靠顏色 |
| Filter chips | 已套用條件與移除按鈕 accessible name 保留 |
| Form errors | per-field error 保留唯一 ID；help 移除後同步重算 `aria-describedby` |
| `AppLayout`／Header／Sidebar | 導覽名稱、目前使用者、我的帳號、主題與登出是正式控制，不是可刪 helper；第 2 章若調整其可見文字，必須先補具體分類 |

## 搜尋基準

- `frontend/src/pages`：22 個正式 TSX 頁面；另有 `pages/salary/shared.tsx` 共用狀態元件，以及測試、helper、CSS 與 `.gitkeep`。
- `frontend/src/components`：10 個正式共用 TSX 元件。
- 初始輔助文字候選：以 `text-fg-muted`／`text-fg-subtle`、description、help、hint、warning、placeholder 搜尋，共同納入逐章查證。
- 初始 `aria-describedby` 使用處：強制改密碼與我的帳號；圖表另以 `aria-labelledby` 同時引用標題與 description。刪減時必須依實際屬性檢查目標 ID。
- 初始 `title=` 使用處：Theme Toggle、User 管理受限操作、車輛照片原始檔名及元件 title props；User 管理不得把 `title` 當唯一 disabled reason。
- 現有前端測試會直接比對 Login、Account、Password Required 與 App Layout 文案；各章修改時改以 role／label 與必要安全文案為主要契約。
