## 正式契約

- App config 是純前端靜態型別設定，不需要 backend runtime API。
- 修改 config 即可同步 Login 主標／副標、Sidebar brand 與 Browser title。
- `document.title` 在呼叫 React `createRoot(...).render(...)` 前完成設定，不依賴頁面 effect。
- Vite 在回傳 dev HTML 或建立 production HTML 時，會從 app config 注入正式 title；build 產物即使停用 JavaScript仍有正確標題。
- `index.html` source 的 `ERPV2` 只作 transform 找不到目標時的安全 fallback，不是第二個正式設定來源。
- 本部分沒有建立 backend settings API、settings table、Settings 頁、Logo upload 或 Theme 設定。
- 沒有修改 `~/website` repo。

## 第二輪 Adversarial Review Follow-up

第二輪 Review 確認前次 F1／F2 修正有效，另指出 replacement string 會把 title 內的 `$` substitution patterns 解讀成 match、文件前後內容或 escaped dollar，以及測試只檢查 source 接線、沒有直接執行 plugin 行為。兩項均有效並完成最小修正：

- Vite HTML transform 改用 function replacement，config title 內的 `$` 保持原字元，不再展開成 match 或文件前後內容。
- 將正式 `app-browser-title` plugin factory 匯出供測試直接呼叫；測試以同一個實際 plugin 驗證四種 `$` pattern、`&`／`<`／`>` HTML escape、完整輸出與 fallback 缺失時的明確失敗。
- 原 consumer 接線檢查改以 TypeScript AST 取得 `appConfig` property access，`document.title` 斷言容許任意空白，不再綁定 JSX 原始排版。
- 正式字串唯一性稽核改查 TypeScript string／JSX literal AST；`companyName` 作為其他名稱的子字串時，不會因註解或較長字串而誤判。
