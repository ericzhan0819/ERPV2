## 正式契約

- `UserResource` 在 `/api/me`、登入回應與 admin users API 均回傳 `username`、`must_change_password`，且不回傳 password／remember token。
- Admin 使用者列表顯示 username；null 固定顯示「尚未設定」，待改密碼帳號顯示「需修改密碼」。
- Admin 建立表單與編輯表單均不提供 username 欄位，username 仍由員工未來透過 self profile UI 維護。
- 建立成功會提示首次登入必須改密碼；重設成功會提示既有登入失效，需以新密碼登入並修改密碼。
- `frontend/src/api/auth.ts` 集中提供 `login`、`me`、self profile 與 self password API。
