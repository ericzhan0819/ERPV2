### 帳號與首次登入

- Admin 建立 sales 帳號後，username 顯示尚未設定，並顯示待修改密碼與正確提示。
- Email／預設密碼登入後立即進入強制改密碼頁。
- 直接輸入 Dashboard 仍被導回強制頁，一般 API 由後端阻擋。
- Theme Toggle、Logout、錯誤目前密碼與正確修改後進 Dashboard 均通過。

### 我的帳號與雙登入

- Header 可進我的帳號，修改名稱後 Header 即時更新。
- Username 可設定，重複值顯示欄位錯誤；Email／角色不可編輯。
- 修改密碼必須目前密碼，confirmation 不符顯示錯誤。
- Username、Email 與 username 大小寫登入均通過，錯誤訊息不洩漏識別方式。

### Admin Reset

- Admin 重設密碼後，User list 顯示待修改密碼。
- 每個既有 stateful Session 在各自下次操作回 `401` 並登出。
- 員工使用新預設密碼登入後進入強制修改密碼頁，完成後恢復 Dashboard。

### Config／Regression

- App config 修改後 Login、Sidebar 與 Browser title 同步。
- Theme Toggle、Admin／manager／sales 既有主要流程無回歸。
- Desktop Chrome 與 Mobile Safari 基本操作通過。
